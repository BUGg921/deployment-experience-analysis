## 部署经验（用户提供的公式推导总结）

以下内容按用户提供的总结写入。

统一关系：

$$
N=256,\qquad B=128,\qquad
DP=\frac{256}{PP\cdot TP},
$$

$$
p_E=\frac{E}{EP\cdot C}=\frac8{EP},
\qquad p_E\le1.
$$

因此专家容量要求 \(EP\ge8\)。另外 batch 硬约束 `128 可被 DP×MB 整除`，至少给出：

$$
DP\cdot MB\le128
$$

从而：

$$
\boxed{\frac{MB}{PP}\le\frac{TP}{2}}.
$$

后面凡是利用这条关系，我都会明确说明它来自**可行性约束**，不是 score 偏好。

### s006 经验与推导

TP：

$$
TP\le8
$$

得到 +20。

EP 中 \(p_E\le0.5\) 被罚，而 \(p_E>0.5\) 得正奖励，所以：

$$
\boxed{E/C\le EP<2E/C}.
$$

MB/PP 项不是简单阈值。低于 1 会扣分，而高于 1 后：

$$
+5(MB/PP-1),
$$

所以：

$$
\boxed{MB/PP\text{ 在可行范围内越大越好}}.
$$

同时：

$$
TP/PP\le1,
$$

即：

$$
\boxed{TP\le PP}.
$$

硬约束又给：

$$
MB/PP\le TP/2.
$$

为了让 MB/PP 尽量大，就会推动 TP 尽量大；而 TP≤PP、PP≤4，所以：

$$
TP\le4.
$$

取：

$$
PP=4,\ TP=4
$$

时，可达到最大：

$$
MB/PP=2,
$$

即：

$$
MB=8.
$$

DP=16。EP 当前离散只能取 8 才有 \(p_E>0.5\)。



**部署经验：**

$$
\boxed{
TP\le PP;\quad
MB/PP\text{尽量大};\quad
TP\le8;\quad
EP\in[E/C,2E/C)
}
$$

当前约束联合收敛：

$$
\boxed{PP4\_TP4\_DP16\_EP8\_MB8}.
$$

## 4. 字段定义代码与评分函数

以下字段定义位于原始 score 上方，已逐一核对全部 90 个候选的特征及评分结果。

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_pp_ratio = MB / PP  # microbatch 数量 / stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_pp_ratio = TP / PP  # 张量并行度 / 流水线并行度
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if ctx.tp_degree <= 8.0:
        score += 20.0
    else:
        score -= 10.0 * hinge_above(ctx.tp_degree, 8.0)
    if ctx.expert_capacity_pressure <= 0.5:
        score -= 5.0
    else:
        score += 5.0
    if ctx.microbatch_pp_ratio < 1.0:
        score -= 20.0 * hinge_below(ctx.microbatch_pp_ratio, 1.0)
    else:
        score += 5.0 * hinge_above(ctx.microbatch_pp_ratio, 1.0)
    if ctx.tp_pp_ratio <= 1.0:
        score += 10.0
    else:
        score -= 5.0 * hinge_above(ctx.tp_pp_ratio, 1.0)
    return score
```

硬约束：PP×TP×DP=256；PP 整除 44；EP 整除 DP 和 192；128 可被 DP×MB 整除；192/EP≤24；规划显存≤57.6 GiB。EP 不额外乘入 GPU 数。
