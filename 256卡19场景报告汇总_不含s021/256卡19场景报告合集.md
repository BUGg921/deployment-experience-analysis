## s004 场景：256 卡 DeepSeek 仿真报告

场景来源：原 256 卡场景 `s004` 的完整保存配置；2026年9月22日批次已重新执行全部候选仿真并独立演化评分函数；本报告于2026年9月25日依据该批次证据重新生成。

### 部署经验（用户提供的公式推导总结）

以下内容按用户提供的总结写入。

统一关系：

$$
N=256,\qquad B=128,\qquad
DP=\frac{256}{PP\cdot TP},
$$

$$
p_E=\frac{E}{EP\cdot C}=\frac8{EP},
\qquad p_E\le1.
$$

因此专家容量要求 \(EP\ge8\)。另外 batch 硬约束 `128 可被 DP×MB 整除`，至少给出：

$$
DP\cdot MB\le128
$$

从而：

$$
\boxed{\frac{MB}{PP}\le\frac{TP}{2}}.
$$

后面凡是利用这条关系，我都会明确说明它来自**可行性约束**，不是 score 偏好。

#### s004 经验与推导

评分首先希望：

$$
0.5\le\frac{TP}{DP}\le2.
$$

同时：

$$
TP\le10,
$$

$$
DP\ge32
$$

有 +20，而：

$$
DP\ge64
$$

还有额外 +5。因此高 DP 是非常明确的偏好。消去 DP：

$$
DP\ge32
\Longrightarrow
PP\cdot TP\le8,
$$

额外奖励区：

$$
DP\ge64
\Longrightarrow
PP\cdot TP\le4.
$$

这与 \(TP/DP\ge0.5\) 无法同时满足，所以比例项不能当作硬条件。进入 \(TP/DP<0.5\) 后，比例得分随 TP/DP 增大而改善，因此正确经验是：

$$
\boxed{\text{优先保持高DP，并在高DP区域内尽量增大TP/DP}}
$$

而不是要求一定进入 `[0.5,2]`。

MB≤1.5，所以正整数下：

$$
\boxed{MB=1}.
$$

EP 要求：

$$
p_E\ge0.9
$$

因此：

$$
E/C\le EP\le10E/(9C).
$$

当前离散 EP 只有 8 满足。

在 `PP×TP≤4` 的额外奖励区里：

$$
TP/DP=\frac{PP\cdot TP^2}{256}
$$

由 `PP=1,TP=4` 最大，所以当前离散关系进一步收敛为：

$$
PP=1,\ TP=4,\ DP=64.
$$



**部署经验：**

$$
\boxed{
DP\ge32，额外偏好DP\ge64；
高DP区域内尽量增大TP/DP；
MB=1；
EP\in[E/C,10E/(9C)]
}
$$

当前离散参数下进一步为：

$$
\boxed{PP1\_TP4\_DP64\_EP8\_MB1}.
$$

### 4. 字段定义代码与评分函数

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    ctx.dp_degree = float(DP)  # 数据并行度
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_count = float(MB)  # microbatch 数量，不是单个 microbatch 的样本数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_dp_ratio = TP / DP  # 张量并行度 / 数据并行度
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


def distance_to(x, a):
    return abs(x-a)  # 与目标 a 的绝对距离


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if 0.5 <= ctx.tp_dp_ratio <= 2.0:
        score += 10.0
    else:
        score -= 10.0 * distance_to(ctx.tp_dp_ratio, 1.0)
    if ctx.tp_degree <= 10:
        score += 10.0
    else:
        score -= 5 * hinge_above(ctx.tp_degree, 10)
    if ctx.dp_degree >= 32:
        score += 20.0
    else:
        score -= 5.0 * hinge_below(ctx.dp_degree, 32)
    if ctx.dp_degree >= 64:
        score += 5.0
    if ctx.microbatch_count <= 1.5:
        score += 10.0
    else:
        score -= 5 * hinge_above(ctx.microbatch_count, 1.5)
    if ctx.expert_capacity_pressure >= 0.9:
        score += 5.0
    else:
        score -= 5.0 * hinge_below(ctx.expert_capacity_pressure, 0.9)
    return score
```

硬约束：PP×TP×DP=256；PP 整除 44；EP 整除 DP 和 192；128 可被 DP×MB 整除；192/EP≤24；规划显存≤57.6 GiB。EP 不额外乘入 GPU 数。

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def group_features(PP, TP, DP, topology, default_compute):
    # 连续 stage-dp-tp 放置；EP 不额外乘入 GPU 总数。
    def rank(stage, replica, lane):
        return (stage * DP + replica) * TP + lane

    groups = {
        "tp": [[rank(s, d, t) for t in range(TP)]
               for s in range(PP) for d in range(DP)],
        "dp": [[rank(s, d, t) for d in range(DP)]
               for s in range(PP) for t in range(TP)],
        "pp": [[rank(s, d, t) for s in range(PP)]
               for d in range(DP) for t in range(TP)],
    }
    def mean(xs):
        return sum(xs) / len(xs)

    result = {}
    for axis, axis_groups in groups.items():
        scopes, slow_links, stragglers = [], [], []
        for group in axis_groups:
            edge_scopes, edge_slowdowns = [], []
            if len(group) > 1:
                for j, src in enumerate(group):
                    dst = group[(j + 1) % len(group)]  # 组内有向通信环，包含闭环边
                    a, b = topology.device(src), topology.device(dst)
                    scope = (0.0 if a.server_id == b.server_id else
                             0.5 if a.affinity_group_id == b.affinity_group_id else 1.0)
                    # 同机=0；同亲和组跨机=0.5；跨亲和组=1。
                    link = topology.link(src, dst)
                    normal = topology.link_profile(link.physical_kind).bandwidth_bytes_s
                    edge_scopes.append(scope)
                    edge_slowdowns.append(max(0.0, 1.0-link.bandwidth_bytes_s/normal))
            scopes.append(mean(edge_scopes) if edge_scopes else 0.0)
            slow_links.append(mean(edge_slowdowns) if edge_slowdowns else 0.0)
            slowest = min(topology.device(r).compute_tflops for r in group)
            stragglers.append(max(0.0, 1.0-slowest/default_compute))
        result[axis+"_scope_exposure"] = mean(scopes)  # 组内边平均，再对组平均
        result[axis+"_slow_link_exposure"] = mean(slow_links)  # 相对同类正常链路的降幅
        result[axis+"_straggler_exposure"] = mean(stragglers)  # 各组最慢卡的降幅均值
    return result


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    grouped = group_features(PP, TP, DP, topology, 312.0)
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_pp_ratio = MB / PP  # microbatch 数量 / stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_pp_ratio = TP / PP  # 张量并行度 / 流水线并行度
    ctx.tp_scope_exposure = grouped["tp_scope_exposure"]  # 计算方式见上方分组函数
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if ctx.tp_scope_exposure <= 0.25:
        score += 10.0
    else:
        score -= 30.0 * hinge_above(ctx.tp_scope_exposure, 0.25)
    if ctx.tp_degree <= 8.0:
        score += 20.0
    else:
        score -= 10.0 * hinge_above(ctx.tp_degree, 8.0)
    if ctx.tp_pp_ratio <= 1.0:
        score += 15.0
    else:
        score -= 5.0 * hinge_above(ctx.tp_pp_ratio, 1.0)
    if ctx.microbatch_pp_ratio >= 2.0:
        score += 20.0
    else:
        score -= 10.0 * hinge_below(ctx.microbatch_pp_ratio, 2.0)
    if ctx.expert_capacity_pressure >= 0.75:
        score += 15.0
    else:
        score -= 10.0 * hinge_below(ctx.expert_capacity_pressure, 0.75)
    return score
```

```python
        "pp": [[rank(s, d, t) for s in range(PP)]
               for d in range(DP) for t in range(TP)],
    }
    def mean(xs):
        return sum(xs) / len(xs)

    result = {}
    for axis, axis_groups in groups.items():
        scopes, slow_links, stragglers = [], [], []
        for group in axis_groups:
            edge_scopes, edge_slowdowns = [], []
            if len(group) > 1:
                for j, src in enumerate(group):
                    dst = group[(j + 1) % len(group)]  # 组内有向通信环，包含闭环边
                    a, b = topology.device(src), topology.device(dst)
                    scope = (0.0 if a.server_id == b.server_id else
                             0.5 if a.affinity_group_id == b.affinity_group_id else 1.0)
                    # 同机=0；同亲和组跨机=0.5；跨亲和组=1。
                    link = topology.link(src, dst)
                    normal = topology.link_profile(link.physical_kind).bandwidth_bytes_s
                    edge_scopes.append(scope)
                    edge_slowdowns.append(max(0.0, 1.0-link.bandwidth_bytes_s/normal))
            scopes.append(mean(edge_scopes) if edge_scopes else 0.0)
            slow_links.append(mean(edge_slowdowns) if edge_slowdowns else 0.0)
            slowest = min(topology.device(r).compute_tflops for r in group)
            stragglers.append(max(0.0, 1.0-slowest/default_compute))
        result[axis+"_scope_exposure"] = mean(scopes)  # 组内边平均，再对组平均
        result[axis+"_slow_link_exposure"] = mean(slow_links)  # 相对同类正常链路的降幅
        result[axis+"_straggler_exposure"] = mean(stragglers)  # 各组最慢卡的降幅均值
    return result


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    grouped = group_features(PP, TP, DP, topology, 312.0)
    ctx.dp_scope_exposure = grouped["dp_scope_exposure"]  # 计算方式见上方分组函数
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_pp_ratio = MB / PP  # microbatch 数量 / stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_dp_ratio = TP / DP  # 张量并行度 / 数据并行度
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def distance_to(x, a):
    return abs(x-a)  # 与目标 a 的绝对距离


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if 0.5 <= ctx.tp_dp_ratio <= 2.0:
        score += 10.0
    else:
        score -= 10.0 * distance_to(ctx.tp_dp_ratio, 1.0)
    if ctx.dp_scope_exposure <= 0.5:
        score += 20.0
    if ctx.tp_degree <= 5:
        score += 10.0
    else:
        score -= 5 * hinge_above(ctx.tp_degree, 5)
    if ctx.tp_degree <= 2:
        score += 5.0
    if ctx.expert_capacity_pressure >= 0.9:
        score += 1e-06
    if ctx.microbatch_pp_ratio >= 1.0:
        score += 1e-06
    return score
```

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_count = float(MB)  # microbatch 数量，不是单个 microbatch 的样本数
    ctx.pp_degree = float(PP)  # 流水线 stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if ctx.tp_degree <= 4.0:
        score += 20.0
    else:
        score -= 10.0 * hinge_above(ctx.tp_degree, 4.0)
    if ctx.pp_degree <= 1.0:
        score += 15.0
    else:
        score -= 5.0 * hinge_above(ctx.pp_degree, 1.0)
    if ctx.microbatch_count <= 1.0:
        score += 5.0
    else:
        score -= 2.0 * hinge_above(ctx.microbatch_count, 1.0)
    if ctx.expert_capacity_pressure >= 1.0:
        score += 10.0
    else:
        score -= 5.0 * hinge_below(ctx.expert_capacity_pressure, 1.0)
    if ctx.tp_degree >= 4.0:
        score += 15.0
    else:
        score -= 5.0 * hinge_below(ctx.tp_degree, 4.0)
    return score
```

硬约束：PP×TP×DP=256；PP 整除 44；EP 整除 DP 和 192；128 可被 DP×MB 整除；192/EP≤24；规划显存≤57.6 GiB。EP 不额外乘入 GPU 数。
