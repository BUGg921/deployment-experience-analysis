## 部署经验（用户提供的公式推导总结）

以下内容按用户提供的总结写入。

统一关系：

$$
N=256,\qquad B=128,\qquad
DP=\frac{256}{PP\cdot TP},
$$

$$
p_E=\frac{E}{EP\cdot C}=\frac8{EP},
\qquad p_E\le1.
$$

因此专家容量要求 \(EP\ge8\)。另外 batch 硬约束 `128 可被 DP×MB 整除`，至少给出：

$$
DP\cdot MB\le128
$$

从而：

$$
\boxed{\frac{MB}{PP}\le\frac{TP}{2}}.
$$

后面凡是利用这条关系，我都会明确说明它来自**可行性约束**，不是 score 偏好。

### s031 经验与推导

MB/PP 的最佳平台：

$$
0.65\le MB/PP\le1.35.
$$

因此：

$$
\boxed{MB\approx PP}.
$$

TP：

$$
\boxed{TP\le4}.
$$

TP/DP 的主奖励平台在正数域中：

$$
0<TP/DP\le5/16.
$$

但是：

$$
TP/DP<1/16
$$

又会有额外惩罚。

所以有效优选区：

$$
\boxed{
1/16\le TP/DP\le5/16
}.
$$

另外，如果：

$$
PP>1
$$

并且已经满足：

$$
TP/DP\ge1/16,
$$

会额外扣 10。

因此进入优选比例区后：

$$
\boxed{PP=1}
$$

明显更好。

PP=1 时：

$$
TP/DP=\frac{TP^2}{256}.
$$

要求：

$$
TP/DP\ge1/16
$$

得到：

$$
TP\ge4.
$$

又有 TP≤4：

$$
\boxed{TP=4}.
$$

因此：

$$
DP=64.
$$

MB≈PP：

$$
MB=1.
$$

EP≤0.5 会扣分，所以当前离散下 EP=8。



**部署经验：**

$$
\boxed{
PP=1;\quad
1/16\le TP/DP\le5/16;\quad
TP\le4;\quad
0.65\le MB/PP\le1.35;\quad
EP<2E/C
}
$$

当前空间：

$$
\boxed{PP1\_TP4\_DP64\_EP8\_MB1}.
$$

## 4. 字段定义代码与评分函数

以下字段定义位于原始 score 上方，已逐一核对全部 90 个候选的特征及评分结果。

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_pp_ratio = MB / PP  # microbatch 数量 / stage 数
    ctx.pp_degree = float(PP)  # 流水线 stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_dp_ratio = TP / DP  # 张量并行度 / 数据并行度
    return ctx


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


def distance_to(x, a):
    return abs(x-a)  # 与目标 a 的绝对距离


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if 0.65 <= ctx.microbatch_pp_ratio <= 1.35:
        score += 10.0
    else:
        score -= 10.0 * distance_to(ctx.microbatch_pp_ratio, 1)
    if ctx.tp_degree <= 4.0:
        score += 5.0
    if -0.1875 <= ctx.tp_dp_ratio <= 0.3125:
        score += 10.0
    else:
        score -= 10.0 * distance_to(ctx.tp_dp_ratio, 0.0625)
    if ctx.expert_capacity_pressure <= 0.5:
        score -= 10.0
    if ctx.tp_dp_ratio < 0.0625:
        score -= 10.0 * hinge_below(ctx.tp_dp_ratio, 0.0625)
    if ctx.pp_degree > 1.0 and ctx.tp_dp_ratio >= 0.0625:
        score -= 10.0
    return score
```

硬约束：PP×TP×DP=256；PP 整除 44；EP 整除 DP 和 192；128 可被 DP×MB 整除；192/EP≤24；规划显存≤57.6 GiB。EP 不额外乘入 GPU 数。
