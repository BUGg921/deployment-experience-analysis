## 部署经验（用户提供的公式推导总结）

以下内容按用户提供的总结写入。

统一关系：

$$
N=256,\qquad B=128,\qquad
DP=\frac{256}{PP\cdot TP},
$$

$$
p_E=\frac{E}{EP\cdot C}=\frac8{EP},
\qquad p_E\le1.
$$

因此专家容量要求 \(EP\ge8\)。另外 batch 硬约束 `128 可被 DP×MB 整除`，至少给出：

$$
DP\cdot MB\le128
$$

从而：

$$
\boxed{\frac{MB}{PP}\le\frac{TP}{2}}.
$$

后面凡是利用这条关系，我都会明确说明它来自**可行性约束**，不是 score 偏好。

### s092 经验与推导

比例目标：

$$
0.5\le TP/DP\le2.
$$

DP≤16 会直接扣 20，因此：

$$
\boxed{DP>16}.
$$

TP：

$$
\boxed{TP\le6}.
$$

PP>1 会按照：

$$
-5(PP-1)
$$

持续扣分，所以：

$$
\boxed{PP=1}.
$$

MB>1 只有 −0.001，是极弱惩罚：

$$
\boxed{MB=1\text{ 为弱偏好}}.
$$

EP：

$$
p_E\ge0.75.
$$

得到：

$$
\boxed{
E/C\le EP\le4E/(3C)
}.
$$

PP=1 后：

$$
DP=256/TP.
$$

TP≤6 的候选是 1、2、4，它们都满足 DP>16。

比例目标仍达不到，但比例分数会随着 TP 增大改善，因此：

$$
\boxed{TP=4}.
$$

于是：

$$
DP=64.
$$

当前 EP 离散只能 8 达到 \(p_E\ge0.75\)。



**部署经验：**

$$
\boxed{
PP=1;\quad
TP\le6;\quad
DP>16;\quad
在该区域内尽量增大TP/DP;\quad
MB=1\text{（弱偏好）};\quad
EP\in[E/C,4E/(3C)]
}
$$

\boxed{PP1\_TP4\_DP64\_EP8\_MB1}.

## 4. 字段定义代码与评分函数

以下字段定义位于原始 score 上方，已逐一核对全部 90 个候选的特征及评分结果。

```python
# 定义说明代码：只构造本 score 实际使用的字段。
# 调用前，候选须通过正整数、整除、专家容量和显存可行性检查。
from types import SimpleNamespace


def build_ctx(PP, TP, EP, MB, topology=None):
    N = 256  # 可用 GPU 数；全部候选用满卡
    E = 192  # 专家总数
    C = 24  # 每个 EP rank 的专家数上限
    B = 128  # 全局 batch
    DP = N // (PP * TP)  # PP×TP 整除 N；DP 不是独立选择
    ctx = SimpleNamespace()
    ctx.dp_degree = float(DP)  # 数据并行度
    ctx.expert_capacity_pressure = (E / EP) / C  # 每个 EP rank 的专家数 / 上限；不是实测利用率
    ctx.microbatch_count = float(MB)  # microbatch 数量，不是单个 microbatch 的样本数
    ctx.pp_degree = float(PP)  # 流水线 stage 数
    ctx.tp_degree = float(TP)  # 张量并行组大小，未取对数或归一化
    ctx.tp_dp_ratio = TP / DP  # 张量并行度 / 数据并行度
    return ctx


def hinge_above(x, a):
    return max(0.0, x-a)  # 超过上界 a 的部分


def hinge_below(x, a):
    return max(0.0, a-x)  # 低于下界 a 的缺口


def distance_to(x, a):
    return abs(x-a)  # 与目标 a 的绝对距离


# 原始评分函数：按原样保留所有条件、阈值及奖惩系数。
def score(ctx):
    score = 0.0
    if 0.5 <= ctx.tp_dp_ratio <= 2.0:
        score += 10.0
    else:
        score -= 10.0 * distance_to(ctx.tp_dp_ratio, 1.0)
    if ctx.dp_degree <= 16.0:
        score -= 20.0
    if ctx.tp_degree <= 6:
        score += 10.0
    else:
        score -= 5 * hinge_above(ctx.tp_degree, 6)
    if ctx.pp_degree > 1.0:
        score -= 5.0 * hinge_above(ctx.pp_degree, 1.0)
    if ctx.microbatch_count > 1.0:
        score -= 0.001
    if ctx.expert_capacity_pressure >= 0.75:
        score += 10.0
    else:
        score -= 30 * hinge_below(ctx.expert_capacity_pressure, 0.75)
    return score
```

硬约束：PP×TP×DP=256；PP 整除 44；EP 整除 DP 和 192；128 可被 DP×MB 整除；192/EP≤24；规划显存≤57.6 GiB。EP 不额外乘入 GPU 数。
